# Спрея

Мобільний веб-застосунок для обробки картоплі на лінії: міряє швидкість потоку,
рахує витрату препаратів і веде облік сесій обробки. Працює офлайн, дані
зберігаються в браузері.

**Застосунок:** https://lemishv.github.io/spreya/ — відкрити на телефоні й
додати на головний екран (Chrome: «Встановити застосунок»; Safari: «На екран
Домівка»).

## Що вміє

| Екран | Задача |
|---|---|
| **Швидкість картоплі** | Секундомір + до 3 ваг («було → стало»). КОЛО фіксує проміжний час, СТОП — фінальний. Результат — кг/хв і кг/год. Є ручний режим («Вручну»), коли ваг немає. |
| **Препарати** | Для кожного препарату з нормою (мл/т) — потрібна витрата мл/хв при поточній швидкості, скільки триває 1 л, і зворотний розрахунок (мл/хв → кг/год). |
| **Сесія** | Сорт, типи ємкостей (тип / розмір / вага), вибрані препарати. Під час роботи: `+1` на кожну ємкість → тоннаж; `+1` на каністру → літри; фактична норма мл/т і відхилення від планової; пауза; корекції; журнал подій. |
| **Підсумок і історія** | Тривалість, ємкості, тоннаж, середня швидкість, розкладка по ємкостях і препаратах. «Поділитися» — текстом через системне меню або в буфер обміну. |
| **Дані** | Експорт/імпорт усіх даних одним JSON-файлом. |

## Формули

```
швидкість [кг/хв]   = Σ(стало − було) [кг] / час кола [хв]
витрата [мл/хв]     = швидкість [кг/хв] × норма [мл/т] / 1000
1 л триває [хв]     = 1000 / витрата [мл/хв]
зворотно [кг/год]   = витрата [мл/хв] × 1000 / норма [мл/т] × 60

тоннаж [кг]         = Σ по типах (кількість × вага + корекція)
фактична норма [мл/т] = літри × 1000 / (тоннаж / 1000)
відхилення [%]      = (факт − норма) / норма × 100
```

Усі розрахунки — у [`calc.js`](calc.js), без DOM; картка сесії, підсумок та
історія користуються однією й тією ж функцією, тож цифри всюди збігаються.

## Структура

```
index.html      розмітка головного екрана
style.css       стилі (контраст тексту ≥ 4,5:1, тач-цілі ≥ 44 px)
calc.js         чисті розрахунки й форматування
app.js          стан, localStorage, рендер екранів, обробники
sw.js           service worker — робота офлайн
manifest.json   PWA-маніфест
fonts/          Fraunces (латиниця) і JetBrains Mono (латиниця + кирилиця), OFL
icons/          іконки застосунку
tests/          автотести (відкрити tests/ у браузері або tools/run-tests.sh)
tools/          службові скрипти
```

Збірки немає — це звичайні файли. Дані лежать у `localStorage` під ключем
`spreya:v1` (формат: див. `serializeState()` в `app.js`); експорт — той самий
об'єкт, загорнутий у `{ app: "spreya", format: 1, data: … }`.

## Розробка

```bash
python3 -m http.server 8765        # відкрити http://localhost:8765/
./tools/run-tests.sh               # тести в headless Chrome (або відкрити /tests/ у браузері)
```

На `localhost` service worker працює в режимі «спершу мережа», тому правки
видно одразу після оновлення сторінки. На проді ресурси віддаються з кешу.

**Реліз.** Підняти версію в трьох місцях однією командою й описати зміни:

```bash
python3 tools/bump_version.py 0.7.1
```

Публікація — GitHub Pages з гілки `main`: злиття в `main` = реліз. Після
оновлення користувачі, у яких застосунок відкритий, побачать тост «Є нова
версія — Оновити».
